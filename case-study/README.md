# Case Study Files

This folder contains the public portfolio materials for the Healthcare Operations Benchmarking case study.

Files include:

- `Healthcare_Operations_Benchmarking_Case_Study.pdf`
- `Healthcare_Operations_Benchmarking_One_Page_Summary.pdf`

The runnable repository implements the weight and fall benchmark measures documented in the main README. The full case study also identifies exploratory analytic extensions that are not implemented in the public pipeline.

The materials are anonymized for public portfolio use. No raw resident-level or personally identifiable data are included.
